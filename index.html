Modules

Extend your toolkit.

NullBusy is built around a plugin-style module system. Each module adds a focused set of features — file utilities, network tools, converters, generators and more. Modules will be distributed through an integrated registry, making installation a single click.

The module system is still under construction. The first official modules will drop alongside the initial public release. Check back soon!

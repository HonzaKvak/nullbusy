Development Status

We're cooking something good.

NullBusy is being built from scratch with a clear vision: replace the clutter of one-purpose tools with a single, fast, extensible platform. The first public build is now available as an early work-in-progress for Windows — rough around the edges, but functional. The roadmap is ambitious and the pace is steady.

~23% complete — Core architecture in progress

Modules

Extend your toolkit.

NullBusy is built around a plugin-style module system. Each module adds a focused set of features — file utilities, network tools, converters, generators and more. Modules will be distributed through an integrated registry, making installation a single click.

📦

No modules available yet

The module system is still under construction. The first official modules will drop alongside a future release. Check back soon!
